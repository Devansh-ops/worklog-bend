# Worklog Bend v0.1.0-preview.1

An independent Bend2-based recreation of
[Tanmay Agrawal's Worklog](https://github.com/tanmayagrawal21/worklog).
Original Git history and the MIT notice are preserved. Bundled Bend-generated
code includes the pinned compiler's Apache 2.0 notice.

- [Hosted app](https://devansh-ops.github.io/worklog-bend/)
- [Synthetic demo](https://devansh-ops.github.io/worklog-bend/?demo=1)
- [Setup](../../SETUP.md), [status](../STATUS.md) and [law review](../LAW_REVIEW.md)

The app provides the board, private tasks, notes/history, search/wiki, reports,
reminders, optional AI and a separate GitHub data repository. Bend owns the pure
domain decisions; JavaScript owns rendering, codecs, storage and external effects.
Publications require approval of the exact immutable commit plan. Conflicts
preserve drafts and require a new preview. Concurrent tabs preserve pending edits.

## Executed validation

Bend 2.0.40 is pinned at `70607d7f740e3b3f4a1edc61069df8ab88491696`.
The real verdict checker accepts 168 root declarations, including support lemmas
and witnesses, rather than 168 separate application guarantees. All 13 mutation
gates, 16 runtime/adapter suites and six real Chromium gates have passed. The
runtime suites include 30 Store groups and 1,004 inherited assertions across four
time zones. Generated assets are checked for reproducibility in CI.

[Live GitHub acceptance](../LIVE_GITHUB_ACCEPTANCE.md) passed with isolated
synthetic data and a credential relay: exact commit readback, whole-tree changes,
real peer conflicts, in-flight edits and fresh-context replay. This exposed and
fixed terminal-newline differences in GitHub's commit-message readback before
approval sealing. All temporary test repositories were removed.

## Preview limits

Proofs cover the stated Bend model, not the compiler, codecs, DOM, browser APIs
or transport. Direct browser token/CORS behavior, live AI authentication, GPU
inference and OS default-browser launching were not executed. Pending journals
are append-only and retain old local content; safe compaction is future work.
See [pending recovery](../PENDING_RECOVERY.md) for retention limits.

GitHub Pages tracks `main`; the hosted demo can advance beyond this tag.
No npm or BendHub package is published by this release.
